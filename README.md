# 🌍 Project Aftershock

## 📌 Project Overview

Project Aftershock is a Python-based data pipeline for collecting and processing earthquake data from the USGS Earthquake API.

The project demonstrates how to collect real-world data, process and clean it, and save the results in a structured format for further analysis.

## 🎯 Project Objectives

- Collect earthquake data from the USGS API.
- Process and clean the collected data.
- Extract useful earthquake information.
- Store raw and processed data.
- Build a simple and organized data pipeline using Python.

## 🛠️ Technologies Used

- Python
- REST API
- USGS Earthquake API
- JSON
- CSV
- Data Processing
